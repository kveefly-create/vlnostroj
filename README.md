# Vlnostroj

Naučte stroj fyziku vlnění. Interaktivní soutěž do fyziky pro 2. ročník SŠ (téma *Mechanické vlnění II – rovnice postupné harmonické vlny*), která spojuje základy strojového učení s procvičením rovnice postupné vlny.

**Spustit:** https://vlnostroj.vercel.app

## Kola soutěže
1. **Kmitání, nebo vlnění?** – klasifikace (perceptron, štítky, příznaky, trénovací a testovací data)
2. **Stroj měří vlnu** – proložení zašuměných dat, chyba MSE, gradientní sestup
3. **Stroj objevuje vzorce** – výběr hypotézy z vyřešených úloh, test na nových úlohách

Každý tým dostane vlastní data podle svého názvu. Po každém kole získá ověřovací kód, který učitel zapíše na tabuli výsledků. Metodika a klíč jsou v záložce *Pro učitele*.

Vše běží v prohlížeči, bez instalace a bez serveru. Stav se ukládá jen lokálně (localStorage).
